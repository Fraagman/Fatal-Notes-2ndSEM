# Fatal-Notes-2ndSEM

All notes provided to batch 2025-29 for End Semester Examination. Also contains PYQs up to Year 2025.

## How To Use

You can browse the repository directly on GitHub, or clone it to your local machine using Git:

```bash
# Clone the repository
git clone https://github.com/Fraagman/Fatal-Notes-2ndSEM.git
```

- **Viewing PDFs/Docs:** Click on any file to view it directly in your browser.
- **Downloading:** Click the `Code` button and select `Download ZIP` to get the entire collection offline.
